# Demo Script

1. Open `http://localhost:5184` and show AgriSense dashboard
2. Open gateway Swagger at `http://localhost:8580/docs`
3. Call `POST /workflow/process-sensor` with low soil moisture value
4. Show alert creation and updated field stats
5. Call `POST /workflow/plan-field-work`
6. Show generated fertilization task in planning module
7. Show yearly yield comparison and economic KPIs
8. Show weather sync and offline map package endpoint
